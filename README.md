# Password Generator

A simple command-line Password Generator built using Python.

This project allows users to generate secure random passwords by choosing:

- Password length
- Whether to include numbers
- Whether to include special characters

The program then generates three different password options for the user to choose from.

---

## Features

- Generate random passwords
- Custom password length
- Optional numbers (0-9)
- Optional special characters (!@#$%^&*)
- Generates 3 password options at once
- Simple command-line interface
- Built using only Python standard libraries

---

## Installation

Clone the repository:

```bash
git clone https://github.com/parthh001/password-generator.git
```

Move into the project folder:

```bash
cd password-generator
```

---

## Usage

Run the Python file:

```bash
python password_generator.py
```

or

```bash
python3 password_generator.py
```
