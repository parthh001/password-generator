# Password Generator

A simple command-line password generator built with Python.

## What it does

- Generates strong random passwords
- You choose the length
- You choose whether to include numbers and special characters
- Gives you 3 options at once to pick from

# Features

- Custom password length
- Optional numbers
- Optional special characters
- Generates 3 password choices
- Simple command-line interface

## How to run

Make sure you have Python installed, then:

```bash
python password_generator.py
```

## Example output

```
================================
      Password Generator        
================================

Password length (press Enter for 12): 16
Include numbers? (y/n): y
Include special characters? (y/n): y

--- Your Generated Password ---
Option 1: aB3$kL9#mNq2Xt7!
Option 2: Rp8@vZ1&nW5#cQ4^
Option 3: Hy6*jF2!oU3$bM9%
```

## Built with

- Python 3
- `random` module (built-in)
- `string` module (built-in)

No external libraries needed.
